Hỗ trợ xuất báo cáo Excel (.xlsx) trực tiếp trên trình duyệt • Tự động lưu dữ liệu cục bộ (LocalStorage)

🔐 Cấu Hình Kết Nối Dữ Liệu Facebook

Chế độ 1 — Kết nối thực tế qua Meta Graph API (Trực tiếp trên Web): Dán mã Access Token của bạn vào bên dưới. Web App sẽ gọi thẳng tới máy chủ graph.facebook.com để lấy danh sách video thật và số lượt xem của Fanpage.

Chế độ 2 — Chế độ Serverless API (Khi đưa lên Vercel): Tự động gọi qua endpoint /api/scan trên project Vercel của bạn.

➕ Nhập Dữ Liệu Video Cho Fanpage Đang Chọn

Bạn có thể dán danh sách video dạng JSON hoặc từng dòng theo cú pháp: Ngày đăng | Nội dung | Views | Likes | Comments | Shares | Link để phân tích và xuất báo cáo Excel ngay trên Web App.

🚀 Cách Đưa Web App Này Lên Vercel (Có Link Online Giống Hệt Mẫu)

Để có một đường link trực tuyến dạng https://ten-app-cua-ban.vercel.app chạy trên mọi máy tính và điện thoại mà không cần cài đặt:

  1. Tải gói FacebookFanpageAnalytics_Vercel_WebApp.zip mình đã đóng gói sẵn bên dưới về máy và giải nén.
  2. Truy cập vercel.com (hoặc đẩy thư mục lên GitHub rồi bấm Import Project trên Vercel).
  3. Bấm Deploy — sau 15 giây, Vercel sẽ cấp cho bạn đường link Web App chạy trực tiếp trên trình duyệt (kèm sẵn Backend Serverless Function tại /api/scan.js để tự động đọc dữ liệu Fanpage từ phía máy chủ mà không bị lỗi chặn CORS của trình duyệt).
